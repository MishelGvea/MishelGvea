### Sobre mí

Desarrollador con enfoque en **backend**, interesado en el diseño de **APIs** y en arquitecturas orientadas a **microservicios**. Disfruto construir servicios bien estructurados, seguros y fáciles de integrar.

Como proyecto académico de gran escala desarrollé **NU-B Studio**, una plataforma de e-commerce para arte de la Huasteca Hidalguense, construida con Node.js, Express, React y PostgreSQL. En él trabajé el diseño de la base de datos, la API REST, la autenticación con JWT y la integración de análisis de seguridad (SAST) con SonarCloud y GitHub Actions.

También tengo experiencia en desarrollo de escritorio con C# y .NET, y trabajo de forma habitual tanto en Linux como en Windows.

**Disponible para estadía profesional** (enero – abril 2027) · CDMX, Monterrey, Querétaro o esquema híbrido.
